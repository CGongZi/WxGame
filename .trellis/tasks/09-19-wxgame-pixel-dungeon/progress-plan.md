> 必达系统：**壳层体验 · 关卡 · 武器 · 天赋 · 货币 · 角色 · 配置后台 · 进度存档 · 微信上线**

## 〇、产品形态（先统一认知）

### 正确的玩家路径（目标形态）

```
启动 Loading / 登录
  →（可选）开场小动画 / Logo
  → 主界面 Lobby（同场景可开战，不是另开一局才出现主角）
  → 玩家在两侧配置（角色/天赋/商店/设置等）
  → 点下方「开始游戏」
  → UI 消退动画 → 摇杆出现 → 直接开玩
  → 结算 / 通关 → 回主界面（按钮再滑入）
```

**禁止**：冷启动直接刷怪开战、或点开始后硬切场景无过渡。

---

### ⭐ 主界面 → 开战 UX 契约（用户确认 2026-09-21）

> 实现 Phase J 时必须按此效果，不要做成「弹一层菜单再 loadScene」。

**主界面布局（Lobby 态）**
1. **登录/进游戏后先到主界面**，不是直接开战。
2. **屏幕下方正中**：唯一主 CTA ——「开始游戏」大按钮。
3. **左右两侧**：其余配置入口（角色、天赋、武器图鉴、商店、设置、排行榜等），对称或分区排布。
4. **主角站在主界面中央可见**（展示当前出战角色），玩家配置时就能看到「自己」。
5. 此时：**摇杆 / 攻击轮盘隐藏**；世界可静置展示或轻待机动画，不进入战斗逻辑。

**点击「开始游戏」后的过渡（开战态）**
1. 所有大厅按钮 **消退**：
   - 两侧配置按钮 **滑出屏幕外**（左往左、右往右），带缓动；
   - 底部「开始游戏」一并淡出/下移消失。
2. 消退完成后（或并行短叠化）：
   - **摇杆（轮盘）出现**（左下常见位置）；
   - 攻击/操作区可用；
   - 主角从「展示态」切到「可操控态」，**当场开玩**（同场景状态切换优先，避免生硬切场景）。
3. 开战后再刷怪 / 启用 DungeonManager 战斗逻辑（大厅态不刷敌或不激活 AI）。

**回大厅（对称反向）**
- 结算或返回时：战斗 UI 收起 → 两侧按钮从屏外滑回 → 底部「开始游戏」再现 → 主角恢复展示待机。

**一句话**：主界面就是带角色的大厅；点开始 = 按钮退场 + 轮盘入场，无缝开玩。

### ⭐ 手机操作契约（用户确认 2026-09-21）

> 横屏触摸操作；实现/改操控时以此为准。**已落地第一版**（`JoystickController` + `WeaponController`）。

| 区域 | 控件 | 行为 |
|------|------|------|
| **左半屏** | 移动轮盘（虚拟摇杆） | 拖动控制角色移动方向与速度 |
| **右半屏** | 攻击键 + 方向轮盘 | 点击/按住发起攻击；可拖动指定攻击朝向 |
| **长按攻击** | 连续开火 | 按住不放则按武器攻速 **连续攻击**；同时可用轮盘 **实时改攻击方向** |
| **松手** | 停止连发 | 松开攻击键停止连续攻击（近战/远程均适用） |

补充：
- Lobby 态：左右轮盘均 **隐藏**；Playing 态随「开始游戏」过渡后可触摸跟手出现。
- 编辑器/PC 可保留 WASD + 鼠标瞄准作调试，但真机以左右双轮盘为准。
- 攻击方向：攻击盘拖动优先；仅移动时用移动方向兜底。

### ⭐ 多地图 · 地形 · 匹配刷怪 · 图鉴（用户确认 2026-09-21）

> 后续硬内容支柱；实现 Phase M / 扩展 B·K 时按此契约，禁止「换皮地板但怪表仍全球乱刷」。

**核心循环**
1. **多种地图主题 + 地形**（洞穴 / 遗迹 / 沼泽 / 冰原…）：地板样式、障碍物形状、碰撞、氛围色不同。
2. **每层（或每房）随机抽一套地图主题**，再按该主题刷怪 —— **地图与怪物匹配**（沼泽出毒蛙，冰原出雪史莱姆，不可全局一张怪表乱塞）。
3. **地形可玩性**：障碍/坑/减速带/可破坏物等按主题表配置，不只是换贴图。
4. **图鉴（局外）**：
   - **地图图鉴**：解锁过的主题、地形说明、出现层段；
   - **怪兽图鉴**：解锁过的怪、归属地图、行为简述、掉落提示；
   - 大厅侧栏「图鉴」入口最终覆盖：**武器 + 地图 + 怪兽**（可分页）。

**数据契约（方向）**
- `MapThemeDef`：id、显示名、地形预制/绘制参数、障碍表、氛围、可出现层段权重
- `EnemyDef.mapThemeIds[]` 或 `BiomeSpawnTable`：主题 → 可刷怪池 + 权重 + 精英/Boss 候选
- 换层时：`rollTheme(floor)` → `buildTerrain(theme)` → `spawnFrom(theme.spawnTable)`
- 首次遭遇/通关主题 → 写入存档解锁图鉴

**禁止**
- 只有一种紫格子地板却号称「多地图」
- 随机地图后仍用与主题无关的固定 10 模板硬编码刷怪
- 图鉴只做武器、不做地图/怪兽（侧栏「图鉴」长期空壳）
