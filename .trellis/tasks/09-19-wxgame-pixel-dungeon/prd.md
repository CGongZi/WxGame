# PRD — WxGame 像素地牢探险

## 目标 & 用户价值

开发一款 **完整的 2D 像素风地牢探险微信小游戏**（可运营、可维护内容），对标元气骑士核心体验：

- 有 **Loading / 开场动画 / 大厅**，不是进去就是战斗
- 随机地牢探索，每局不同
- 收集武器 / 装备 / 道具，越战越强
- 打怪 → Boss → 下一层 → 通关结算 → 回大厅
- 局外养成：天赋、商店、角色解锁
- **运营后台**可维护角色、武器、道具、关卡等配置并上传资源
- 最终发布到微信小游戏，面向国内休闲玩家

| 限制项 | 数值 |
|--------|------|

| 社交 | 排行榜（开放数据域）、分享卡片 |

| 内容更新 | 配置包 + CDN 资源；提审包必须内置可离线默认配置 |

## 产品信息架构

### 玩家侧流程
```
启动 → Loading → 开场小动画（可跳过）→ 大厅
  大厅按钮：开始 / 继续 / 角色 / 武器图鉴 / 天赋 / 商店 / 设置 / 排行榜 / 分享
  → 出战确认 → 进局 → 结算/通关 → 回大厅
```

### 运营侧流程
```
CMS 登录 → 编辑角色/武器/怪物/关卡/道具/天赋/经济
        → 上传贴图/音效/JSON → 校验发布配置包
        → 客户端拉取或随版本内置 → 局内读表生效
```

## 核心玩法设计

### 游戏循环
```
大厅出战 → 地牢(5层) → 探索击杀 → Boss → 下一层
                ↓
        拾取装备/武器/道具；局内商店
                ↓
        死亡 → 广告复活 or 结算回大厅
        通关 → 通关结算 → 回大厅（灵魂石等奖励）
```

### 角色系统
- 多角色可选（非仅 1 个占位骑士）
- 属性：HP、攻击、防御、移速、暴击等（表驱动）
- 技能：基础攻击 + 可扩展主动技能
- 数据来源：本地配置包 / CMS 发布包

### 武器系统（元气骑士风格）
| 类别 | 示例 | 攻击方式 |
|------|------|---------|
| 近战 | 剑、锤子 | 近距挥砍 |
| 远程 | 弓箭、魔杖 | 抛射物 |
| 特殊 | 爆炸物、魔法 | 范围 AoE |

- 稀有度：普通 / 稀有 / 史诗
- 局内掉落 + 局外图鉴解锁
- **属性与解锁条件由配置/CMS 维护**

### 道具系统
- 消耗品（回血等）、被动、宝箱
- CMS 可新增/改属性、图标、掉落

### 怪物系统
| 怪物 | 行为 |
|------|------|
| 普通小怪 | 追击近战（归属主题池） |
| 远程怪 | 弓手保持距离射击 |
| 幽魂 | 飞越障碍贴脸 |
| 暗法师 | 远程慢速法球 |
| Boss | 多阶段；优先主题匹配或层段覆盖 |
| 图鉴 | 首次遭遇解锁；未解锁剪影 |

### 地牢
- 当前实现：开放世界大地图 + 传送门换「层」+ 单一地形色板
- 目标：
  - 层/波/Boss/`FloorConfig` 表驱动，可被 CMS 编辑
  - **多种地图主题 + 地形**；**每层随机主题**
  - **怪物与地图匹配**（主题刷怪池，禁止全球乱刷）
  - 局外 **地图图鉴 + 怪兽图鉴**（与武器图鉴并列）

### 天赋 / 货币
- 局外天赋树（灵魂石）
- 局内金币 + 局外灵魂石商店
- （可选）局内三选一强化 → **已做**（F4 TalentPick）

## 内容后台（CMS）需求 — 硬需求

### 目标
让非程序员也能维护局内内容：新增角色/武器/道具/**地图主题**/怪物归属、改属性、上传资源、发版控制客户端。

### 功能清单（MVP → 完整）
1. **管理员登录**
2. **CRUD**：角色、武器、怪物、**地图主题/地形**、**主题刷怪池**、关卡、道具、天赋、掉落、经济数值、图鉴文案
3. **文件上传**：贴图、音效、配置 JSON；预览
4. **发布**：草稿 → 校验 Schema → 生成带 version 的配置包 → 全量/灰度
5. **回滚**：按 version 回退
6. **审计**：谁在何时改了什么

### 与客户端契约
- 统一 Schema（见 `design.md`）
- 客户端：`内置默认包` 必须可离线通关；远程包可选增强
- 改配置不要求每次重新提审（资源/数值类）；大改玩法需评估审核

## 技术栈

| 模块 | 选型 | 原因 |
|------|------|------|
| 游戏引擎 | **Cocos Creator 3.8** | 微信小游戏官方支持 |
| 语言 | **TypeScript** | 类型安全 |
| 配置 | JSON 配置包 + `ConfigStore` | 可 CMS 发版、可降级 |
| 后台 | Web 管理端 + 轻量 API（独立 `admin/`） | 运营维护 |
| 存储 | 对象存储 / 静态 CDN | 资源与配置包分发 |
| 微信 SDK | wx API + Cocos 适配层 | 登录/广告/分享/排行榜 |
