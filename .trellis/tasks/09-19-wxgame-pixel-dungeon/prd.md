# PRD — WxGame 像素地牢探险

## 目标 & 用户价值

开发一款 **2D 像素风地牢探险微信小游戏**，对标元气骑士的核心体验：
- 随机生成地牢房间，每局不同
- 收集武器/装备，越战越强
- 打怪兽 → 通关 Boss → 进入下一层
- 轻松上手，深度耐玩，碎片化时间可玩
- 最终发布到微信小游戏平台，面向国内休闲玩家

---

## 平台约束（微信小游戏）

| 限制项 | 数值 |
|--------|------|

| 变现 | 激励视频广告（复活/加速）、流量主 Banner |

## 核心玩法设计

### 游戏循环
```
开始局 → 随机地牢(5层) → 每层：探索房间 → 击杀怪物 → 找到Boss房 → 击败Boss → 下一层
                                ↓
                        拾取装备/武器/道具
                                ↓
                        死亡 → 看广告复活 or 结束 → 结算
```

### 角色系统
- **1个初始角色**（MVP），后续可扩展
- 属性：HP、攻击力、防御、移动速度
- 技能：1个基础攻击 + 1个主动技能

### 武器系统（元气骑士风格）
| 类别 | 示例 | 攻击方式 |
|------|------|---------|
| 近战 | 剑、锤子 | 近距挥砍 |
| 远程 | 弓箭、魔杖 | 抛射物 |
| 特殊 | 爆炸物、魔法 | 范围 AoE |

- 稀有度：普通 / 稀有 / 史诗（3级）
- 随机掉落，每局重置

### 怪物系统（MVP 3类）
| 怪物 | 行为 |
|------|------|
| 普通小怪 | 追击玩家，近战攻击 |
| 远程怪 | 保持距离，射击 |
| Boss | 多阶段，特殊技能，掉落必得装备 |

### 地牢生成
- 预制房间模板（10～20个）+ 随机拼接
- 每层 5～8 个房间
- 房间类型：普通战斗 / 宝箱 / 商店 / Boss

## 技术栈

| 模块 | 选型 | 原因 |
|------|------|------|
| 游戏引擎 | **Cocos Creator 3.8** | 官方微信小游戏支持，国内生态最好 |
| 语言 | **TypeScript** | 类型安全，Cocos 原生支持 |
| 像素渲染 | Cocos 2D Sprite + Tilemap | 轻量，支持 WebGL |
| 物理 | Cocos 内置 Box2D Lite | 碰撞检测够用，不过度消耗 |
| 地图编辑 | **Tiled Map Editor** + TMX | 与 Cocos 无缝对接 |
| 像素素材 | **Kenney 像素资产包**（CC0免费） | 快速启动，风格统一 |
| 音效 | **BFXR**（本地生成） + Freesound | 8-bit 音效 |
| 背景音乐 | **BeepBox**（在线合成）/ Suno AI | 轻快像素风 BGM |
| 微信 SDK | wx API + Cocos 微信适配层 | 官方方案 |
